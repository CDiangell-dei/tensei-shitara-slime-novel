# 🌀 Tensei Shitara Slime Datta Ken — Biblioteca & Leitor Completo em Português

Aplicação web estática, moderna e 100% em **Português Brasileiro (PT-BR)** dedicada a reunir, revisar, higienizar e disponibilizar para leitura todo o universo de **Tensei Shitara Slime Datta Ken** (*That Time I Got Reincarnated as a Slime*), obra de **Fuse** ilustrada por **Mitz Vah**.

🔗 **Acesse o Leitor Online:** **https://cdiangell-dei.github.io/tensei-shitara-slime-novel/**

Funciona diretamente no navegador (computador, tablet ou celular) pelo **GitHub Pages** ou localmente de forma 100% offline, contando com **salvamento automático de progresso** (`localStorage` + backup `.json`), separação estrita entre **Light Novel** e **Web Novel**, trilha sonora dinâmica por mudança de cena, **123 caixinhas de explicação interativas** (perfeitas para leituras ao vivo e streamers), centenas de ilustrações oficiais em WebP HD e links diretos para as edições oficiais na **Amazon Brasil**.

## 💻 Como Executar Localmente (100% Offline)

Se desejar baixar o repositório para ler em viagens ou sem conexão com a internet:

### No Windows (1 Clique)
Dê um duplo clique no arquivo **`Iniciar_Leitor.bat`** na raiz do projeto. Ele abre o servidor local em `http://localhost:8080`.

### Em Qualquer Sistema Operacional (Python 3)
Abra o terminal na pasta do projeto e execute:
```bash
python -m http.server 8080
```
Em seguida, acesse **`http://localhost:8080`** no seu navegador favorito.
